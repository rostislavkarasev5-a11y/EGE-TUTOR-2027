# Шаблоны для импорта задач

- `tasks_template.yaml` — удобнее для длинных условий и решений; в файле есть описание всех полей.
- `tasks_template.csv` — можно открыть и заполнить в Excel. Разделитель — точка с запятой,
  кодировка UTF-8 или Windows-1251 (обе понимаются). Несколько навыков или файлов —
  через запятую. Десятичная дробь в ответе — через запятую или точку.

Свои файлы с задачами храни в `data/private_content/` — эта папка не попадает в Git.

Проверка без записи: `ege import путь/к/файлу`. Запись: `ege import путь/к/файлу --apply`.
Отмена импорта: `ege imports` (узнать номер) → `ege undo-import НОМЕР`.
