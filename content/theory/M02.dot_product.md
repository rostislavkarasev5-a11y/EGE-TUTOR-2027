## Что нужно знать

Скалярное произведение двух векторов — это число. Его можно найти двумя способами:

- через длины и угол: a · b = |a| · |b| · cos φ, где φ — угол между векторами;
- через координаты: если a(x1; y1), b(x2; y2), то a · b = x1 · x2 + y1 · y2.

Отсюда косинус угла между векторами:

- cos φ = (x1 · x2 + y1 · y2) / (|a| · |b|).

Важные следствия:

- a · b = 0 тогда и только тогда, когда векторы перпендикулярны (если оба ненулевые);
- a · b > 0 — угол острый, a · b < 0 — угол тупой;
- скалярный квадрат равен квадрату длины: a · a = |a|^2;
- |a + b|^2 = |a|^2 + 2 · a · b + |b|^2.

Табличные косинусы: cos 0° = 1, cos 30° = sqrt(3)/2, cos 45° = sqrt(2)/2, cos 60° = 1/2, cos 90° = 0, cos 120° = −1/2, cos 135° = −sqrt(2)/2, cos 180° = −1.

## Как решать

1. Даны координаты — считай скалярное произведение по координатам.
2. Даны длины и угол — используй формулу с косинусом.
3. Нужен угол — найди скалярное произведение, длины векторов и cos φ, затем угол по таблице.
4. Нужна длина суммы или разности при известных длинах — возведи в квадрат и раскрой скобки, как в формуле квадрата суммы.
5. Условие перпендикулярности записывай как уравнение a · b = 0.

## Частые ошибки

- Перемножены только длины векторов, без cos φ.
- В координатной формуле сложены x1 + x2, а не перемножены.
- Знак косинуса не учтён: при отрицательном скалярном произведении угол больше 90°.
- При поиске |a + b| забыто удвоенное скалярное произведение.
