## Что нужно знать

Функция F(x) называется первообразной для f(x), если F'(x) = f(x). Это «обратное действие» к нахождению производной.

У каждой функции бесконечно много первообразных: если F(x) — одна из них, то все остальные имеют вид F(x) + C, где C — любое число.

Первообразные основных функций:

- для f(x) = k (число): F(x) = kx + C;
- для x^n (n ≠ −1): F(x) = x^(n + 1) / (n + 1) + C;
- для 1/x (x > 0): F(x) = ln x + C;
- для e^x: F(x) = e^x + C;
- для sin x: F(x) = −cos x + C;
- для cos x: F(x) = sin x + C.

Первообразная суммы — сумма первообразных, числовой множитель выносится.

Площадь под графиком. Если f(x) ≥ 0 на отрезке [a; b], то площадь фигуры между графиком, осью Ox и прямыми x = a, x = b равна:

- S = F(b) − F(a) — формула Ньютона — Лейбница;
- константа C при вычитании сокращается, поэтому подойдёт любая первообразная.

## Как решать

1. Дана первообразная, спрашивают значение функции — найди производную первообразной и подставь точку.
2. Спрашивают F(b) − F(a) и формула F известна — просто посчитай два значения и вычти.
3. Нужна конкретная первообразная — запиши общий вид с C и найди C из условия (точка на графике).
4. Задача на площадь:
- найди границы фигуры (если не заданы — нули функции);
- убедись, что функция на отрезке не отрицательна;
- найди первообразную и вычисли F(b) − F(a).

## Частые ошибки

- Перепутаны производная и первообразная: для x^2 первообразная x^3/3, а не 2x.
- Забыта константа C там, где она нужна (поиск первообразной через точку).
- Вычитание в обратном порядке: S = F(b) − F(a), из значения на правом конце вычитаем значение на левом.
- Неверные границы фигуры: не найдены точки пересечения графика с осью Ox.
- Потерян знак при подстановке отрицательных чисел: (−3)^3 = −27.
