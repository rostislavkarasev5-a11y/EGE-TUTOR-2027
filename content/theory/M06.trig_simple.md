## Что нужно знать

Простейшие уравнения — это sin x = a, cos x = a, tg x = a. Удобно решать их по единичной окружности: угол x — это поворот точки, cos x — её абсцисса, sin x — ордината.

Табличные значения (углы в градусах):

- sin 30° = 1/2, sin 45° = sqrt(2)/2, sin 60° = sqrt(3)/2, sin 90° = 1;
- cos 30° = sqrt(3)/2, cos 45° = sqrt(2)/2, cos 60° = 1/2, cos 0° = 1;
- tg 30° = sqrt(3)/3, tg 45° = 1, tg 60° = sqrt(3).

Общие формулы (n — любое целое число):

- cos x = a, |a| ≤ 1: x = ±arccos a + 2πn;
- sin x = a, |a| ≤ 1: x = arcsin a + 2πn или x = π − arcsin a + 2πn;
- tg x = a: x = arctg a + πn (для любого a).

Если |a| > 1, у уравнений sin x = a и cos x = a корней нет.

Полезно помнить: arcsin(−a) = −arcsin a, arctg(−a) = −arctg a, а arccos(−a) = π − arccos a.

## Как решать

1. Приведи уравнение к виду sin t = a, cos t = a или tg t = a, где t — аргумент (например, t = πx/6).
2. Выпиши все серии корней для t.
3. Если аргумент сложный, вырази x из каждой серии: умножь или раздели обе части, перенеси сдвиг.
4. Подставляй n = 0, ±1, ±2, … и выпиши несколько корней каждой серии.
5. Выбери тот корень, который просят: наименьший положительный, наибольший отрицательный, лежащий на отрезке.

Перевод из радиан в градусы: умножить на 180/π. Например, π/3 = 60°.

## Частые ошибки

- Потеряна вторая серия у синуса (π − arcsin a) или знак «±» у косинуса.
- У тангенса взят период 2π вместо π.
- Корни выбраны только из одной серии — проверять нужно все серии.
- Перепутаны «наибольший отрицательный» и «наименьший отрицательный»: наибольший отрицательный — ближайший к нулю слева.
- Ответ записан в радианах, хотя просили градусы (или наоборот).
