## Что нужно знать

**Линейное уравнение** ax + b = 0 при a ≠ 0 имеет один корень x = −b / a.

**Квадратное уравнение** ax^2 + bx + c = 0 (a ≠ 0):

- дискриминант D = b^2 − 4ac;
- если D > 0 — два корня x = (−b ± sqrt(D)) / (2a);
- если D = 0 — один корень x = −b / (2a);
- если D < 0 — корней нет.

Теорема Виета для x^2 + px + q = 0: x1 + x2 = −p, x1 · x2 = q. Удобно для быстрой проверки и подбора целых корней.

Неполные квадратные уравнения решаются проще: x^2 − 9 = 0 даёт x = ±3, а x^2 − 5x = 0 раскладывается как x(x − 5) = 0.

**Дробно-рациональное уравнение** содержит x в знаменателе. Делить на ноль нельзя, поэтому сначала выписывают ОДЗ — значения x, при которых знаменатели не равны нулю.

## Как решать

1. Для дробного уравнения выпиши ОДЗ: все знаменатели не равны нулю.
2. Избавься от дробей: умножь обе части на общий знаменатель (или приравняй числители, если знаменатели одинаковы).
3. Раскрой скобки, перенеси всё в одну сторону, приведи подобные.
4. Реши получившееся линейное или квадратное уравнение.
5. Проверь каждый корень по ОДЗ и выбрось те, что в неё не входят.
6. Если корней несколько, прочитай условие: в ответ идёт меньший или больший.

## Частые ошибки

- Не проверили ОДЗ: корень, обращающий знаменатель в ноль, — посторонний.
- Ошибка в знаке при переносе слагаемого через знак «=».
- При умножении на общий знаменатель умножили не все слагаемые (забыли правую часть).
- В формуле корней забыли, что делить нужно на 2a, а не на 2.
- Записали в ответ не тот корень: если корней несколько, в ответе укажите меньший или больший — как сказано в условии.
- Дробный ответ записывается десятичной дробью: 3/2 — это 1,5.
