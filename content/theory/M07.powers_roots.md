## Что нужно знать

Свойства степеней (a > 0, b > 0, показатели — любые числа):

- a^m · a^n = a^(m + n);
- a^m / a^n = a^(m − n);
- (a^m)^n = a^(m·n);
- (a·b)^n = a^n · b^n, (a/b)^n = a^n / b^n;
- a^0 = 1, a^(−n) = 1 / a^n;
- a^(1/n) — корень n-й степени из a, a^(m/n) = (корень n-й степени из a)^m.

Свойства корней (a ≥ 0, b ≥ 0):

- sqrt(a) · sqrt(b) = sqrt(a·b), sqrt(a) / sqrt(b) = sqrt(a/b) при b > 0;
- (sqrt(a))^2 = a;
- sqrt(a^2) = |a| — для любого a, модуль обязателен.

Полезные формулы сокращённого умножения: (a − b)(a + b) = a^2 − b^2, (a ± b)^2 = a^2 ± 2ab + b^2.

## Как решать

1. Посмотри, какие основания есть в выражении. Часто их можно привести к одному: 4 = 2^2, 8 = 2^3, 27 = 3^3, 81 = 3^4.
2. Десятичные показатели переведи в обыкновенные дроби: 0,75 = 3/4, 1,5 = 3/2.
3. Сначала упрощай выражение в общем виде, а потом подставляй числа — так меньше вычислений.
4. С корнями: объединяй их в один корень и выделяй полный квадрат (sqrt(48) · sqrt(3) = sqrt(144)).
5. Проверь знак: отрицательное число в нечётной степени остаётся отрицательным.

## Частые ошибки

- Показатели перемножены вместо сложения: a^2 · a^3 = a^5, а не a^6.
- Степени с разными основаниями «склеены»: 2^3 · 3^2 нельзя записать как 6^5.
- Корень из суммы разбит на сумму корней: sqrt(9 + 16) = 5, а не 3 + 4.
- Отрицательный показатель воспринят как отрицательное число: 2^(−3) = 1/8, а не −8.
- Потерян знак: (−2)^3 = −8, а (−2)^4 = 16.
