## Что такое случайная величина

Случайная величина — это число, которое зависит от исхода опыта: число очков на кубике, число попаданий, выигрыш в лотерее.

Дискретную случайную величину задают **распределением**: списком её возможных значений и вероятностей этих значений.

- Например: X = 1 с вероятностью 0,2; X = 2 с вероятностью 0,5; X = 3 с вероятностью 0,3.
- Сумма вероятностей всех значений всегда равна 1. Это помогает найти пропущенную вероятность.

## Математическое ожидание

Математическое ожидание E(X) — это «среднее значение» случайной величины, если повторять опыт очень много раз.

- E(X) = x1 · p1 + x2 · p2 + … + xn · pn — каждое значение умножаем на его вероятность и складываем.
- Если все n значений равновероятны, E(X) — обычное среднее арифметическое этих значений.

## Свойства

- E(c) = c для постоянного числа c.
- E(c · X) = c · E(X).
- E(X + Y) = E(X) + E(Y) — для любых случайных величин, даже зависимых.
- Отсюда E(aX + bY + c) = a · E(X) + b · E(Y) + c.
- Число успехов в n независимых испытаниях с вероятностью успеха p в каждом имеет ожидание n · p.

## Как решать

1. Выпиши все значения случайной величины.
2. Найди вероятность каждого значения (по классической формуле, через умножение или сложение вероятностей). Проверь, что сумма вероятностей равна 1.
3. Посчитай сумму произведений «значение × вероятность».
4. Если величина — сумма более простых (число попаданий нескольких стрелков), можно сложить их ожидания, не строя распределение.

## Частые ошибки

- Складывают значения и делят на их количество, хотя вероятности значений разные.
- Сумма вероятностей не равна 1: забыли какое-то значение (например, ноль попаданий).
- В задачах про выигрыш забывают вычесть цену билета, а она платится всегда.
- Математическое ожидание не обязано быть одним из значений: у кубика оно 3,5.
