# ADR-0009: Правила Exam Mode

- Статус: Accepted
- Дата: 2026-10-07

## Решение

Exam Mode (реализация — Phase 9) обеспечивает правила на уровне CORE, а не интерфейса:

1. `AIService` физически не вызывается: в сессию Exam Mode порт ИИ не передаётся.
2. Подсказок нет.
3. Решений нет.
4. После финализации ответ изменить нельзя.
5. Повторно решать тот же вопрос в рамках попытки нельзя.
6. Правильный ответ нельзя увидеть до завершения всей попытки.
7. Используются только разрешённые проверенные задания: `OFFICIAL_FIPI` / `OPEN_BANK` со статусом `REVIEWED`.
8. Фиксированное время, как на экзамене.

После завершения: проверка, баллы, перевод в тестовую шкалу, анализ времени и ошибок, прогноз готовности.

## Последствия

Каждое правило должно быть покрыто тестом в Phase 9, включая тест, что `AIService` не вызывается ни разу за экзаменационную попытку.
