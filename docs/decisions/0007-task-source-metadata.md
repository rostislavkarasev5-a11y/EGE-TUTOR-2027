# ADR-0007: Метаданные источника задачи и пометка AI-задач

- Статус: Accepted
- Дата: 2026-10-07

## Решение

Каждая задача (модель — Phase 1) обязательно хранит:

| Поле | Обязательно | Значение |
|---|---|---|
| `source` | да | `OFFICIAL_FIPI`, `OPEN_BANK`, `USER_MATERIAL`, `AI_GENERATED` |
| `source_ref` | да | точная ссылка на происхождение |
| `source_version` | нет (NULL) | версия источника или спецификации |
| `verification_status` | да | `UNVERIFIED`, `AUTO_CHECKED`, `REVIEWED`, `DISPUTED`, `REJECTED` |

- Перечисления уже есть в `ege_tutor.core.domain.content`.
- `AI_GENERATED` задачи всегда показываются с явной меткой и никогда не выдаются за задания ФИПИ. Гарантия — на уровне CORE и тестов, а не интерфейса.
- Официальные материалы ФИПИ имеют высший приоритет при подборе задач.
- Импорт — единый конвейер с валидацией, поиском дублей, отчётом и откатом пачки (`import_batch`).

## Последствия

Задачу без источника и статуса проверки нельзя сохранить. Контент из сборников и ФИПИ хранится только локально (ADR-0004).
