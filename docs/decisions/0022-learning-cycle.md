# ADR-0022: Учебный цикл: теория, примеры, самостоятельные, разбор, домашка (Phase 8)

- Статус: Accepted
- Дата: 2026-10-12
- Дополняет: архитектура, раздел 5.3 (учебный автомат); ADR-0015 (ошибки и повторения),
  ADR-0017 (ИИ), ADR-0019 (план на день), ADR-0021 (теория по подразделам)

## Контекст

Сейчас программа умеет давать задачи, проверять ответы, считать освоение, планировать день и
проверять номер контрольной. Но новую тему ученику не по чему изучать: теории нет, примеров нет,
и после ошибок нет понятного маршрута «разобрался → закрепил → сдал домашку». Архитектура
(раздел 5.3) описывает учебный блок как конечный автомат, который можно прервать и продолжить.
Эту фазу и нужно сделать, а также самопроверку части 2 без ИИ и Python для информатики.

## Решение

### 1. Единица обучения — навык

Учебный блок открывается по **навыку** из `content/*/topics.yaml` (сейчас 49 навыков по
математике и 35 по информатике). Подразделы Решу ЕГЭ уже связаны с навыками (ADR-0021), поэтому
отдельной теории «по подразделу» не нужно: подраздел показывает теорию своего навыка.

### 2. Теория и 7 примеров — в Git, пишет Claude

- Файл `content/theory/<код навыка>.md`: заголовок (YAML) с `skill`, `source: AI_GENERATED`,
  `version`; затем текст своими словами: что нужно знать, формулы, типовой приём, частые ошибки.
- 7 разобранных примеров в том же файле (от простого к сложному): условие, шаги решения, ответ. Числа выдуманы. Ответы
  примеров проверяют тесты в `tests/content/` (как у стартового банка, ADR-0016).
- На странице всегда видна пометка «Теория написана ИИ (Claude) и проверена тестами; это не
  материал ФИПИ».
- Тексты ФИПИ, учебников и Решу ЕГЭ не копируются.
- Теория пишется постепенно, отдельными PR: сначала номера части 1, потом части 2. Если теории
  для навыка ещё нет, блок честно начинается с примеров из банка и пишет «теории пока нет».

### 3. Шаги блока (конечный автомат)

`ТЕОРИЯ → ПРИМЕРЫ → САМОСТОЯТЕЛЬНЫЕ → ПРОВЕРКА → РАЗБОР ОШИБОК → ЗАДАЧИ НА ОШИБКИ → ДОМАШКА → ГОТОВО`

| Шаг | Что делает ученик | Как CORE решает, что дальше |
|---|---|---|
| Теория | читает, жмёт «Прочитал» | переход сразу |
| Примеры | смотрит 7 примеров по шагам, жмёт «Понял» | переход сразу |
| Самостоятельные | решает `independent_tasks` задач (по умолчанию 10), подсказки можно, но они учитываются | после последней задачи |
| Проверка | видит итог: сколько решено верно и самостоятельно | если доля ≥ `pass_share` (0.8) и ошибок нет → сразу «Домашка» |
| Разбор ошибок | по каждой ошибке видит решение и выбирает причину (правила ADR-0015 предлагают, ИИ может предложить) | после разбора всех ошибок |
| Задачи на ошибки | решает по `mistake_tasks` (2) новых задачи на каждый навык с ошибкой | после последней задачи |
| Домашка | задачи на следующий день, режим `HOMEWORK`: `homework_base` (8) плюс `homework_per_mistake` (2) за каждый навык с ошибкой, но не больше `homework_max` (15) | после последней задачи |
| Готово | блок закрыт; дальше навык живёт в обычной очереди повторений (ADR-0015) | — |

- Состояние блока и все его попытки хранятся в базе: блок можно прервать и продолжить с того же
  шага. Попытки никогда не удаляются.
- Задачи берутся из банка навыка (проверенные, не решавшиеся недавно). Если задач не хватает,
  шаг делается с тем, что есть, и программа пишет об этом. Похожие задачи от ИИ можно добавить
  как сейчас (ADR-0017), они помечены `AI_GENERATED`.
- Пока в банке мало задач (в стартовом банке по 3 на номер), 10 самостоятельных и домашка
  наберутся только после импорта задач Решу ЕГЭ (ADR-0021) или с похожими задачами от ИИ;
  до этого шаги делаются с тем, что есть, и программа это пишет.
- Один открытый блок на навык. Блок можно бросить: он помечается «брошен», попытки остаются.

### 4. План на день

- Новый вид пункта плана `LESSON` — «следующий шаг учебного блока» (архитектура, 5.6). Планировщик
  предлагает блок по самому слабому навыку, по которому блок ещё не проходили, если есть время
  после повторений и ошибок.
- Домашка попадает в план следующего дня как обязательный пункт `HOMEWORK`.
- Правило 80/20 и дисциплина (ADR-0019) работают для этих пунктов так же.

### 5. Самопроверка части 2 без ИИ

- Для каждого номера части 2 Claude пересказывает своими словами критерии оценивания ФИПИ
  (`content/exam_specs/2027/criteria/*.yaml`, со ссылкой на источник и пометкой «пересказ, сверить с
  официальными критериями»).
- После решения ученик отмечает, какие пункты критерия у него есть. CORE считает балл по правилам
  критерия и сохраняет оценку со статусом `SELF` («самооценка»).
- Оценка ИИ (`AI_PRELIMINARY`, ADR-0017) остаётся отдельной. Если оценок две, в mastery идёт
  меньшая.

### 6. Python для информатики

- Для навыков информатики, которые решаются программой, теория содержит шаблон программы на
  Python и разбор, а самостоятельные задачи решаются в поле для программы (песочница, Phase 3).
- Отдельный блок «Python для ЕГЭ» по навыкам темы `I00` (основы языка, функции и рекурсия).

### 7. ИИ в учебном цикле

- Кнопка «Объясни иначе» у теории и примеров: ИИ пересказывает сохранённый текст, ответ помечен
  «ИИ, предварительно». Без ИИ кнопки нет, теория показывается как есть.
- В домашке и задачах на ошибки ИИ-подсказки работают как в тренировке. В контрольной и
  диагностике ИИ по-прежнему нет.

### 8. Настройки и данные

- `config/learning.toml`: `examples` (7), `independent_tasks` (10), `pass_share`, `mistake_tasks`,
  `homework_base` (8), `homework_per_mistake` (2), `homework_max` (15), `homework_due_days`,
  `fresh_days`.
- Миграция 0010: таблицы `lesson` (навык, шаг, статус, даты) и `lesson_attempt` (связь с
  попытками); поле `status` оценки части 2 получает значение `SELF`.
- Сайт: страница «Учёба» (список блоков, начать/продолжить), страница блока по шагам, «Теория» у
  номера задания. CLI: `ege learn НАВЫК`, `ege lessons`, `ege theory НАВЫК`.

Владелец подтвердил решение 2026-10-12 и задал числа: 7 примеров, 10 самостоятельных задач,
домашка — сколько нужно, но не больше 15.

## Последствия

- У каждой новой темы появляется понятный маршрут, и план на день сам ведёт по нему.
- Основная работа фазы — тексты теории. Код блока и самопроверки — один PR; теория — несколько
  PR по номерам. Пока теории нет, блок работает на примерах из банка.
- Mastery не меняется: попытки блока — обычные попытки с режимами `PRACTICE` и `HOMEWORK`.
- Критерии части 2 — пересказ; при выходе официальной демоверсии 2027 их нужно сверить
  (Phase 11).

## Рассмотренные альтернативы

- **Теорию генерирует ИИ на лету.** Дёшево по времени, но тексты каждый раз разные, их нельзя
  проверить тестами, и без ключа ИИ теории не было бы вовсе.
- **Единица обучения — номер задания ЕГЭ.** Слишком крупно: в одном номере (например, №1
  планиметрия) 9 разных навыков, и разобраться с ошибкой в одном из них было бы трудно.
- **Строгий автомат без пропусков.** Если ученик уже всё решил верно, разбор ошибок и задачи на
  ошибки ему не нужны, поэтому эти шаги пропускаются.
