# ADR-0001: Фиксировать архитектурные решения в ADR

- Статус: Accepted
- Дата: 2026-10-07

## Контекст

Проект ведётся по фазам, код пишет Claude в разных сессиях. Владелец проекта утвердил архитектуру v2 и запретил менять её без своего согласия. Нужен способ, который делает каждое решение видимым и проверяемым.

## Решение

- Каждое архитектурное решение записывается как ADR в `docs/decisions/`.
- Изменение утверждённой архитектуры, стека, структуры данных или правил обучения: остановиться → описать проблему → предложить изменение в ADR со статусом `Proposed` → дождаться подтверждения владельца → только потом реализовывать.
- Принятые ADR не редактируются по существу; изменения — новым ADR.

## Последствия

Любая сессия Claude может восстановить контекст по ADR и `CLAUDE.md`. Изменения архитектуры идут медленнее, но осознанно.
