# ADR-0006: Mastery v0 — экспериментальная конфигурируемая модель

- Статус: Accepted
- Дата: 2026-10-07

## Контекст

Нужна оценка освоения навыков с первого дня, хотя реальных данных пользователя ещё нет.

## Решение

Mastery v0 — стартовая гипотеза, а не окончательная истина. Реализация — Phase 4.

Свидетельство попытки:

```
e = correctness × independence × time_factor × repeat_factor,   e ∈ [0, 1]
```

Каждый множитель лежит в [0, 1] (это проверяет загрузчик конфигурации), поэтому `e` всегда в [0, 1]. **Сложность на `e` не умножается.**

Вес свидетельства:

```
w = difficulty_weight × mode_weight
```

Сложность и режим (тренировка, контрольная, диагностика, пробник, экзамен) влияют только на вес — насколько сильно попытка сдвигает оценку навыка.

- Все коэффициенты — в `config/mastery.toml` (`model_version = "v0"`).
- Модель — сменный модуль `MasteryModel`; с каждым значением хранится `model_version`.
- Сырые попытки хранятся всегда, mastery можно пересчитать по истории.
- Калибровка — по `prediction_log` (предсказанная вероятность → факт; Brier score, log-loss). Новая версия включается, только если точнее старой.

## Последствия

Тесты проверяют свойства модели (например, `e ∈ [0, 1]`, подсказка не выгоднее самостоятельного решения), а не конкретные числа.
