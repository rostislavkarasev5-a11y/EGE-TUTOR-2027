# ADR-0021: Импорт задач со страниц Решу ЕГЭ и теория по подразделам

- Статус: Accepted
- Дата: 2026-10-12
- Дополняет: ADR-0004 (публичный репозиторий), ADR-0007 (метаданные задач), ADR-0011 (импорт)

## Контекст

Ученик хочет решать на сайте не только задачи стартового банка, но и задачи Решу ЕГЭ
(sdamgia.ru), и иметь полную теорию по каждому подразделу каталога заданий Решу ЕГЭ. На карточке
решения 2026-10-08 ученик выбрал способ «Импорт со страницы»: он сам сохраняет страницу Решу ЕГЭ
файлом и загружает её на сайт.

Ограничения:

- Репозиторий публичный (ADR-0004): задачи из сборников и с чужих сайтов в Git не попадают.
  Решу ЕГЭ — чужой сайт, его задачи и решения — чужие тексты.
- Задачи Решу ЕГЭ во многом взяты из открытого банка ФИПИ, но проверить это по каждой задаче
  мы не можем, поэтому выдавать их за задания ФИПИ нельзя (принципы 6–7).
- Автоматически обходить сайт (скачивать страницы роботом) не будем: это нагрузка на чужой
  сервер и нарушение его правил. Работаем только с тем, что ученик сохранил сам.
- Разметка Решу ЕГЭ может меняться без предупреждения.

## Решение

### 1. Как ученик добавляет задачи

1. На Решу ЕГЭ открывает подборку: подраздел каталога, вариант или свою подборку, — так,
   чтобы были видны ответы (кнопка показа решений).
2. Сохраняет страницу: `Ctrl+S` → «Веб-страница, только HTML».
3. На нашем сайте: «Импорт» → «Страница Решу ЕГЭ» → выбирает предмет и файл.
4. Видит предпросмотр (ADR-0011): сколько задач нашлось, номер ЕГЭ каждой, есть ли ответ,
   картинки, дубли и ошибки. Записываются только задачи после кнопки «Добавить».

### 2. Что извлекается и как хранится

- Разбор страницы — стандартная библиотека Python (`html.parser`), без новых зависимостей.
  Парсер сделан под реальную разметку Решу ЕГЭ: для этого ученик один раз присылает пример
  сохранённой страницы. Пример используется только для разработки и в Git не попадает; тесты
  работают на страницах-образцах, которые пишет Claude (выдуманные задачи с той же разметкой).
- Из каждой задачи: номер задачи на Решу ЕГЭ, номер задания ЕГЭ, название подраздела, условие,
  ответ, решение (если есть на странице), ссылки на картинки.
- Поля по ADR-0007: `source = USER_MATERIAL` (материал, который добавил ученик),
  `source_ref = «Решу ЕГЭ, задача №<id>, подраздел «…»»`, `source_version = «Решу ЕГЭ 2027»`.
  На сайте у задачи видно «Решу ЕГЭ», а не «ФИПИ».
- Статус проверки: `REVIEWED`, если на странице есть ответ (ключ сайта); без ответа —
  `UNVERIFIED`, такую задачу программа не выдаёт, пока ученик не впишет ответ. Неверный
  ключ ученик отмечает как спорный (уже есть с Phase 2).
- Номер ЕГЭ берётся со страницы. Если номер на странице не найден, ученик выбирает его в
  предпросмотре. Подраздел привязывается к навыку нашего каталога по таблице в
  `content/reshu_ege/subsections.yaml` (только названия подразделов и коды навыков — это не
  задачи, их можно хранить в Git). Неизвестный подраздел — предупреждение, задача
  импортируется без навыка.
- Картинки: сервер один раз скачивает только картинки, на которые ссылается загруженная
  страница (не больше `max_images` на файл из конфигурации), и хранит их в
  `data/private_content/assets/`, как файлы задач (ADR-0011). Страницы сервер не скачивает.
- Всё хранится только на сервере (база и `data/private_content/`) и попадает в ночные бэкапы.
  В Git — только код парсера, таблица подразделов и тестовые образцы Claude.
- Дубли: по хэшу (ADR-0011) и по номеру задачи Решу ЕГЭ — одну задачу второй раз не добавить.
- Отмена пачки — как у любого импорта: задачи скрываются, история остаётся.

### 3. Теория по подразделам

- Теорию пишет Claude своими словами, по подразделам каталога Решу ЕГЭ для 2027 года:
  определения, формулы, типовые приёмы, 2–3 разобранных примера с выдуманными числами,
  частые ошибки. Тексты с Решу ЕГЭ не копируются.
- Каждый текст помечен как написанный ИИ и проверенный тестами там, где есть вычисления
  (как стартовый банк, ADR-0016). Хранится в `content/theory/` в Git.
- Список подразделов ученик присылает скриншотами (по одному на номер задания).
- Теория — часть учебного цикла Phase 8 (теория → примеры → самостоятельные). До Phase 8 она
  показывается простой страницей «Теория» у номера задания.

### 4. Порядок работ

1. PR «Импорт страниц Решу ЕГЭ» (сразу после Phase 7): парсер, предпросмотр на сайте и в CLI
   (`ege import-reshu ФАЙЛ`), таблица подразделов, тесты на образцах.
2. Теория по подразделам — по мере поступления списков, отдельными PR по предметам.

Владелец подтвердил решение («Утвердить») 2026-10-12.

## Уточнения при реализации (2026-10-12)

По присланным примерам страниц выяснилось и сделано так:

- Ответы и решения есть только на **странице результатов** (после кнопки «Завершить работу,
  свериться с ответами, увидеть решения»). Её ученик и сохраняет. Если загрузить сам вариант
  (без ответов), импорт объясняет, какую страницу нужно сохранить.
- Отдельной команды `ege import-reshu` нет: обычная `ege import ФАЙЛ.html [--apply]` и обычная
  форма «Импорт» на сайте понимают страницу `.html`. Предмет определяется по заголовку
  страницы, выбирать его не нужно.
- Подраздел, которого нет в таблице, получает навыки по умолчанию для своего номера
  (`default` в `subsections.yaml`), чтобы задача всё-таки влияла на mastery.
- Рисунки и файлы к задачам (например, `.txt` и `.xls` в информатике) скачиваются только по
  https с адресов `*.sdamgia.ru`, без перенаправлений на другие сайты; лимит — 60 файлов на
  страницу и 10 МБ на файл (константы в коде). Рисунки показываются прямо в условии.
- Формулы на странице — картинки с текстовой подписью; в условие попадает подпись
  («синус A = 0,8»), простые дроби записываются как `(a)/(b)`.

## Последствия

- Задачи Решу ЕГЭ решаются на сайте с таймером, подсказками, mastery и повторениями.
- Если Решу ЕГЭ поменяет разметку, импорт честно скажет «задачи не найдены» и потребуется
  обновить парсер по новому примеру страницы.
- Подсказки ИИ к таким задачам работают как к любым другим; условие задачи отправляется в
  Yandex AI Studio только вместе с запросом подсказки, как и сейчас (ADR-0017).
- В Exam Mode (Phase 9) задачи Решу ЕГЭ можно использовать в пробниках, но с пометкой
  источника.

## Рассмотренные альтернативы

- **Ученик присылает задачи Claude в чат.** Медленно и зависит от Claude; задачи проходили бы
  через чат, хотя должны храниться только на сервере.
- **Автоматическое скачивание с Решу ЕГЭ по ссылке или по каталогу.** Удобнее, но это обход
  чужого сайта роботом: нагрузка, правила сайта, риск блокировки сервера.
- **Новый источник `RESHU_EGE` в списке источников.** Точнее, но меняет структуру данных;
  `USER_MATERIAL` с понятным `source_ref` честно описывает, откуда задача, без изменений схемы.
- **Копировать теорию с Решу ЕГЭ.** Нельзя: чужие тексты в публичном репозитории.
