# ADR-0002: CORE + порты + TutorApp; ИИ предлагает, CORE решает

- Статус: Accepted
- Дата: 2026-10-07

## Контекст

Claude API не должен быть самим приложением. Приложение обязано владеть данными, историей, правилами и работать без ИИ. CLI сейчас и Web в будущем не должны дублировать логику.

## Решение

```
CLI / WEB → TutorApp (фасад) → CORE → MATH / INFORMATICS tutors → порты
порты: Repository, AIService, Sandbox, Clock
```

- Вся логика — в CORE. Интерфейсы только показывают данные и передают ввод в `TutorApp`.
- CORE зависит от протоколов (`ege_tutor.core.ports`), а не от SQLite, Claude API, Docker или системного времени.
- **ИИ предлагает → CORE принимает решение → CORE записывает результат.** Ответы ИИ проверяются CORE и сохраняются с пометкой «оценено ИИ».
- Каждый порт имеет реализацию, работающую без внешних сервисов: `DisabledAIService`, `UnavailableSandbox`, `FixedClock` / `SystemClock`. Хранилище — с Phase 1.
- Сырые попытки пользователя никогда не удаляются; снимки mastery и прогнозов не переписываются задним числом (инвариант порта `Repository`).

## Последствия

Web (Phase 12) подключается к тому же `TutorApp` без переписывания CORE. CORE тестируется без интернета, денег за API и ожидания. Нельзя вызывать Claude API, SQLite или Docker из CLI или из сервисов CORE напрямую — только через порты.
