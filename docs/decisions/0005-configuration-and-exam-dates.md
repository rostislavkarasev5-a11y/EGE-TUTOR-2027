# ADR-0005: Конфигурация в TOML + Pydantic, даты экзаменов TBD

- Статус: Accepted
- Дата: 2026-10-07

## Решение

- Конфигурация — `config/app.toml`, `config/mastery.toml`, `config/diagnostics.toml`. Загружается `ege_tutor.config.load_settings()` и проверяется моделями Pydantic со строгим режимом: неизвестный ключ — ошибка, а не тихое игнорирование.
- Папка конфигурации: аргумент → переменная `EGE_TUTOR_CONFIG_DIR` → `config/` репозитория.
- **Даты экзаменов не хардкодятся.** До официального расписания: `status = "TBD"`, даты нет (`NULL`). Дата задаётся только вместе с `status = "OFFICIAL"` и `source`; иначе конфигурация не загрузится.
- Правила, которые нельзя ослабить конфигурацией, закреплены типами. Пример: в диагностике `hints_allowed` и `ai_allowed` могут быть только `false`.

## Последствия

Коэффициенты и пороги меняются без изменения кода. Пока дата TBD, обратный отсчёт показывается как «не утверждена»; планировщик (Phase 7) будет использовать явно помеченный плановый горизонт, который нигде не выдаётся за реальную дату.
