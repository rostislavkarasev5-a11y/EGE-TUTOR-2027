# ADR-0017: ИИ-слой через Yandex AI Studio

- Статус: Accepted
- Дата: 2026-10-08
- Меняет: ADR-0003 (строка «ИИ: anthropic SDK — с Phase 6»). Дополняет: ADR-0002, ADR-0009

## Контекст

Phase 6 добавляет ИИ-слой: объяснения, подсказки, разбор ошибок, предварительную оценку части 2,
генерацию похожих задач с проверкой. По ADR-0003 первой реализацией должен был стать Claude API
(anthropic SDK). У владельца уже есть аккаунт Yandex Cloud с грантом; оплатить Claude API из России
сложнее. Архитектура (ADR-0002) это допускает: ИИ — заменяемый сервис за портом `AIService`.
Но смена поставщика — изменение стека, поэтому фиксируем её здесь.

## Решение

1. **Первая реализация `AIService` — `YandexAIService`** через Yandex AI Studio, по его
   OpenAI-совместимому API (Chat Completions по HTTPS). Запросы — стандартной библиотекой Python
   (`urllib`), **новой зависимости нет**. anthropic SDK в Phase 6 не добавляется; адаптер Claude
   можно добавить позже за тем же портом отдельным решением.
2. **Настройки** — в `config/app.toml`, раздел `[ai]`: `provider = "disabled" | "yandex"`
   (по умолчанию `disabled`), имя модели (не зашито в код), лимит трат в месяц в рублях, цены
   за 1000 токенов (владелец переносит их с сайта Yandex Cloud), лимит токенов на ответ.
3. **Секреты** — только в переменных окружения на сервере: `EGE_YANDEX_API_KEY` и
   `EGE_YANDEX_FOLDER_ID`. Они не попадают в Git и в чат: владелец сам создаёт в консоли
   сервисный аккаунт с ролью для языковых моделей и API-ключ и сам вписывает их в `.env` на
   сервере по инструкции. `scripts/check_secrets.py` дополняется шаблоном ключей Yandex Cloud.
4. **Бюджет** — CORE считает токены из каждого ответа и стоимость по ценам из конфига, хранит
   учёт по месяцам в базе. При достижении лимита ИИ выключается до следующего месяца и честно
   пишет об этом; всё остальное работает. Дополнительно владелец может включить уведомление о
   расходах в биллинге Yandex Cloud.
5. **Что уходит в Яндекс** — только текст задачи, эталонное решение, ответ и (для части 2)
   решение ученика. Имя, цели, расписание и другие личные данные не отправляются. Запросы
   отправляются с запретом логирования на стороне Яндекса, если API это поддерживает.
6. **Правила ИИ не меняются** (ADR-0002, ADR-0009): ИИ предлагает → CORE решает и записывает;
   всё от ИИ помечено «ИИ, предварительно»; ответ проверки CORE ИИ не переопределяет;
   сгенерированные задачи — `AI_GENERATED`, `UNVERIFIED`, и выдаются только после проверки
   (SymPy / песочница); в Exam Mode и диагностике `AIService` не передаётся вообще.
7. **Тесты** — без интернета и без денег: поддельный сервер ИИ в тестах; настоящий Яндекс в CI
   не вызывается.

## Последствия

- ИИ можно включить на гранте Yandex Cloud без зарубежной оплаты.
- Качество ответов YandexGPT по математике и программированию может быть ниже, чем у Claude;
  поэтому всё от ИИ остаётся предварительным и проверяется CORE. Модель меняется в конфиге.
- Без ключа (`provider = "disabled"`) приложение работает как сейчас.

## Рассмотренные альтернативы

- **Claude API (anthropic SDK)** — сильнее в рассуждениях, но нужен платный ключ и зарубежная
  оплата; остаётся возможным вторым адаптером.
- **Официальный SDK Яндекса / openai SDK** — удобнее, но это новая зависимость ради нескольких
  HTTP-запросов.
- **Без ИИ** — бесплатно, но владелец хочет использовать грант.

Владелец подтвердил решение («Утвердить») 2026-10-08.
