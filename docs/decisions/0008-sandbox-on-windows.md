# ADR-0008: Sandbox на Windows — Docker Desktop, запасной WSL2

- Статус: Accepted
- Дата: 2026-10-07

## Контекст

Python-код пользователя должен выполняться изолированно с ограничениями по времени, CPU, RAM, процессам, файловой системе и сети (по умолчанию сеть выключена). Пользователь работает на Windows, где такие ограничения без контейнера или Linux не сделать.

## Решение

- Основной вариант — **Docker Desktop** (`--network none`, лимиты памяти и CPU, `--pids-limit`, read-only ФС, `--cap-drop ALL`).
- Запасной — **WSL2**: приложение работает внутри Linux, изоляция через Linux-механизмы (`unshare --net`, `setrlimit`).
- Sandbox реализуется **только в Phase 3**. До этого порт `Sandbox` реализует `UnavailableSandbox`, который честно сообщает о недоступности.
- Параметры по умолчанию — в `config/app.toml`, секция `[sandbox]`.

## Последствия

В Phase 3 пользователю понадобится установить Docker Desktop по пошаговой инструкции. Набор тестов sandbox (бесконечный цикл, переполнение памяти, fork, сеть, запись вне рабочей папки) обязателен.
