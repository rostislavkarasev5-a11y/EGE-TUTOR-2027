# ADR-0010: PyYAML для файлов контента

- Статус: Accepted
- Дата: 2026-10-07

## Контекст

Каталог тем, структура экзаменов и шаблоны импорта задач хранятся как данные в `content/`
(архитектура, раздел 5.6). Условия задач — длинный многострочный текст с формулами; в TOML
и CSV такой текст писать и читать неудобно. Стандартная библиотека Python YAML не читает.
Стек ADR-0003 PyYAML не упоминал.

## Решение

Добавить зависимость `pyyaml` (>= 6.0.2, < 7) в Phase 1.

- Файлы читаются только через `yaml.safe_load`: никакого выполнения кода из файла.
- YAML — основной формат каталога и импорта; CSV поддерживается для заполнения в Excel.
- Конфигурация программы остаётся в TOML (ADR-0005).

Владелец подтвердил решение («Добавить PyYAML») 2026-10-07.

## Последствия

Одна небольшая зрелая зависимость без сетевых функций. Каталог и задачи удобно редактировать
вручную; ошибки в файлах выдаются с понятным текстом.

## Рассмотренные альтернативы

- Только CSV — неудобно для многострочных условий и решений.
- JSON — нет комментариев, неудобно писать вручную.
- TOML для задач — громоздко для списков задач с длинным текстом.
