# Roadmap EGE-TUTOR-2027

Правило: каждая фаза — цель → реализация → тесты → проверка → исправления → отчёт «что готово» → отдельный PR. Следующая фаза начинается только после подтверждения владельца проекта. Будущие фазы заранее не реализуются.

| № | Фаза | Что будет готово | Действия пользователя | Статус |
|---|---|---|---|---|
| **0** | Фундамент | Структура проекта, uv, Ruff, pytest, Hypothesis, CI (Linux + Windows), защита от публикации секретов, конфигурация (`app`, `mastery`, `diagnostics`), порты `Repository` / `AIService` / `Sandbox` / `Clock`, фасад `TutorApp`, CLI `ege --version` и `ege info`, документация и ADR. | Нажать «Merge» по инструкции. | готово |
| **1** | Данные, каталог и импорт контента | SQLite + SQLAlchemy 2 + Alembic, профиль, даты экзаменов TBD, структура экзаменов (provisional), темы и навыки, модель задачи с обязательными `source` / `source_ref` / `verification_status` и `source_version`, конвейер импорта с отчётом и откатом, шаблоны импорта, `install.bat` / `update.bat`, команды `ege profile/exam/topics/import/imports/undo-import/tasks/task`. | Установить Git и uv, запустить `install.bat`. Начать собирать материалы. | готово |
| **2** | Решение задач | Проверка кратких ответов (SymPy — вспомогательно), таймер и нормативы времени, 5 уровней подсказок, попытки, самостоятельность, проверка эталонных ответов пользователем; команды `ege solve/review/attempts`. | Порешать тестовые задачи, дать обратную связь. | готово |
| **3** | Python Sandbox | Docker Desktop (основной), WSL2 / Linux-native (запасной), лимиты, тест-кейсы, вердикты, тесты на «злые» программы. | Установить Docker Desktop. | — |
| **4** | Mastery v0, ошибки, повторения | `MasteryModel` v0 по `config/mastery.toml`, `prediction_log`, пересчёт по истории, классификация ошибок правилами, паттерны, очередь повторений, снимки истории. | — | — |
| **5** | Банк задач и адаптивная диагностика | Стартовый банк (`REVIEWED`), адаптивный движок диагностики, предварительный baseline и прогноз. | Передать материалы, пройти диагностику. | — |
| **6** | AI Layer | Клиент Claude, объяснения, подсказки, разбор ошибок, предварительная оценка части 2, генерация задач с проверкой, бюджет, офлайн-режим. | Ключ Anthropic API и лимит трат (если решено подключать). | — |
| **7** | Расписание, план, дисциплина | Шаблон недели, события, чек-ин, планировщик дня, 80/20, перенос по объективным причинам, дисциплина, контрольная при пропуске темы. | Внести расписание и события. | — |
| **8** | Учебный цикл | Теория → 3 примера → самостоятельные → проверка → разбор → задачи на ошибки → домашка → повторение; Python для информатики; самопроверка части 2. | Ежедневное использование. | — |
| **9** | Exam Mode и пробники | Полные варианты по правилам ADR-0009, перевод баллов, анализ времени и ошибок, прогноз. | Пройти пробник. | — |
| **10** | Аналитика | Главная панель, тренды, слабые темы, сравнение периодов. | — | — |
| **11** | Надёжность и калибровка | Бэкапы, обновление, обработка сбоев, спецификация по демоверсии 2027 и официальные даты, первая калибровка mastery. | Указать папку для бэкапов. | — |
| **12** | Web (будущее) | FastAPI поверх того же `TutorApp`. CORE не меняется. | Решить, нужен ли доступ с телефона. | — |
