Импорт задач

Задачи с Решу ЕГЭ

  1. На сайте Решу ЕГЭ составь вариант из нужных подразделов и открой его.
  2. Внизу нажми «Завершить работу, свериться с ответами, увидеть решения».
  3. На странице результатов нажми Ctrl+S и выбери «Веб-страница, только HTML».
  4. Загрузи сохранённый файл .html ниже. Рисунки сайт скачает сам.

Задачи остаются только в твоей базе на сервере и помечаются источником «Решу ЕГЭ».
